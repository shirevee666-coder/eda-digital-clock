# 实验报告模板：EDA 多功能数字钟

> 本模板可直接复制到 Word 中整理成正式实验报告。

## 一、实验名称

EDA 多功能数字钟设计

## 二、实验目的

1. 掌握 Verilog HDL 层次化设计方法；
2. 掌握 60 进制计数器和 24 进制计数器的设计；
3. 掌握数字钟主体电路的组成方式；
4. 掌握七段数码管显示译码方法；
5. 掌握 Quartus 工程建立、编译、引脚分配和 FPGA 下载流程；
6. 了解按键校时、闹钟和整点提示等扩展功能的实现方法。

## 三、实验环境

| 项目 | 内容 |
|---|---|
| 软件 | Quartus Prime Lite Edition |
| 硬件 | DE2-115 FPGA 开发板 |
| FPGA 器件 | Cyclone IV E EP4CE115F29C7 |
| 设计语言 | Verilog HDL |
| 输入时钟 | 50 MHz |

## 四、设计任务

本实验要求设计一个多功能数字钟，基本功能如下：

1. 显示小时、分钟、秒钟；
2. 秒、分采用 60 进制计数；
3. 小时采用 24 进制计数；
4. 能够调整小时和分钟；
5. 能够通过七段数码管显示当前时间。

扩展功能包括：

1. 12/24 小时显示切换；
2. 简易闹钟设定与匹配提示；
3. 整点 LED 闪烁提示。

## 五、总体设计方案

数字钟系统主要由分频模块、秒计数器、分计数器、小时计数器、校时模块、显示译码模块和扩展功能模块组成。

系统输入为 DE2-115 板载 50 MHz 时钟，经分频模块产生 1 Hz 秒脉冲。秒计数器每秒加一，当秒计数到 59 后回到 00，并向分计数器产生进位；分计数器计满 59 后回到 00，并向小时计数器产生进位；小时计数器按 24 进制规律从 00 计数到 23，再回到 00。

当前时间以 BCD 码形式送入七段数码管译码模块，最终通过 HEX0 到 HEX5 显示秒、分、时。

## 六、模块设计说明

### 1. 分频模块 divider.v

分频模块将开发板输入的 50 MHz 时钟分频为 1 Hz 信号，作为数字钟计时脉冲。该模块使用计数器记录输入时钟周期，当计数达到半周期设定值时翻转输出时钟。

### 2. 60 进制计数器 counter60.v

60 进制计数器用于秒和分钟，计数范围为 00 到 59。输出采用 8 位 BCD 码，高 4 位表示十位，低 4 位表示个位。

### 3. 24 进制计数器 counter24.v

24 进制计数器用于小时，计数范围为 00 到 23。当计数值为 23 时，下一次进位使其回到 00。

### 4. 七段数码管译码模块 bcd7seg.v

该模块将 4 位 BCD 数转换为七段数码管段码。由于 DE2-115 的 HEX 数码管一般为低电平点亮，因此模块默认输出低有效段码。

### 5. 按键脉冲模块 key_pulse.v

按键脉冲模块用于处理机械按键输入，通过同步、消抖和边沿检测，使一次按键动作只产生一个有效脉冲，避免按键抖动造成多次计数。

### 6. 核心模块 clock_core.v

核心模块完成数字钟主体逻辑，包括秒、分、小时计数，校时校分，12/24 小时显示切换，闹钟比较和整点提示。

### 7. 顶层模块 top_de2_115.v

顶层模块负责连接 DE2-115 开发板上的时钟、按键、拨动开关、数码管和 LED，并实例化数字钟核心模块。

## 七、引脚分配

本设计使用 `pin/de2_115_pin_assignment.qsf` 进行引脚约束。主要引脚如下：

| 信号 | 功能 |
|---|---|
| `CLOCK_50` | 50 MHz 板载时钟 |
| `KEY[0]` | 复位 |
| `KEY[1]` | 小时加一 |
| `KEY[2]` | 分钟加一 |
| `KEY[3]` | 闹钟分钟加一 |
| `SW[0]` | 计时使能 |
| `SW[1]` | 12/24 小时显示切换 |
| `SW[2]` | 闹钟小时加一 |
| `SW[3]` | 闹钟开关 |
| `HEX0~HEX5` | 六位七段数码管显示 |
| `LEDR[0]` | 闹钟匹配提示 |
| `LEDR[1]` | 整点闪烁提示 |

## 八、仿真与编译结果

在 Quartus 中完成工程建立后，将 `src/` 目录下所有 Verilog 文件加入工程，并将顶层实体设置为 `top_de2_115`。选择 FPGA 器件为 `EP4CE115F29C7`，导入 DE2-115 引脚约束文件后进行编译。

编译结果显示：

```text
Full Compilation was successful.
0 errors
```

说明设计代码和引脚约束均能通过 Quartus 综合、布局布线和时序分析。

## 九、上板现象

下载程序到 DE2-115 开发板后，六位数码管显示当前时间。其中：

| 数码管 | 显示内容 |
|---|---|
| `HEX5 HEX4` | 小时 |
| `HEX3 HEX2` | 分钟 |
| `HEX1 HEX0` | 秒钟 |

打开 `SW[0]` 后，秒显示开始递增。当秒从 59 回到 00 时，分钟加一；当分钟从 59 回到 00 时，小时加一。按下 `KEY[1]` 可调整小时，按下 `KEY[2]` 可调整分钟。切换 `SW[1]` 可观察 12/24 小时显示变化。

## 十、问题分析

实验过程中可能遇到的主要问题包括：

1. 顶层实体名设置错误，导致 Quartus 找不到设计实体；
2. 没有添加全部 Verilog 文件，导致模块缺失；
3. 没有导入引脚约束，导致开发板显示异常；
4. 器件型号选择错误，导致编译或引脚分配不匹配；
5. 按键抖动导致一次按键产生多次响应。

针对这些问题，本设计通过设置正确顶层实体、使用层次化模块结构、提供 QSF 引脚约束文件和按键消抖模块进行解决。

## 十一、实验总结

通过本次实验，完成了基于 Verilog HDL 的多功能数字钟设计。实验中使用层次化方法将系统划分为分频、计数、显示译码、校时和扩展功能等模块，使设计结构更加清晰，便于调试和维护。

本实验加深了对 60 进制计数器、24 进制计数器、BCD 编码、七段数码管显示和 FPGA 引脚约束的理解。同时，通过 Quartus 编译和 DE2-115 上板验证，进一步熟悉了从 HDL 代码到 FPGA 实际运行的完整流程。
