# EDA 多功能数字钟设计

本仓库用于《实验六：EDA 多功能数字钟》Verilog HDL 工程。

## 功能目标

- 24 小时制数字钟：`00:00:00` 到 `23:59:59` 循环计数；
- 秒、分采用 60 进制计数；
- 小时采用 24 进制计数；
- 支持按键校时、校分；
- 支持 12/24 小时显示切换；
- 支持简易闹钟比较输出；
- 支持整点 LED 闪烁提示；
- 提供 testbench 进行功能仿真。

## 推荐 Quartus 使用方式

1. 新建 Quartus 工程，工程名建议为 `eda_digital_clock`。
2. 将 `src/` 下所有 `.v` 文件加入工程。
3. 若使用 DE2-115 开发板，顶层实体选择 `top_de2_115`。
4. 若只做 ModelSim/Quartus 功能仿真，可使用 `sim/tb_clock_core.v`。
5. 编译前根据实际开发板完成引脚分配。

## 顶层端口约定

`top_de2_115.v` 使用常见 DE2-115 命名：

- `CLOCK_50`：50 MHz 系统时钟；
- `KEY[0]`：低电平复位；
- `KEY[1]`：小时加一；
- `KEY[2]`：分钟加一；
- `KEY[3]`：闹钟分钟加一；
- `SW[0]`：计时使能；
- `SW[1]`：12/24 小时显示切换；
- `SW[2]`：闹钟小时加一；
- `SW[3]`：闹钟开关；
- `HEX0~HEX5`：秒、分、时六位数码管显示；
- `LEDR[0]`：闹钟匹配输出；
- `LEDR[17:1]`：整点闪烁/状态指示。

## 说明

当前版本采用可综合 Verilog-2001 写法，尽量避免 SystemVerilog 语法，适合 Quartus 课程实验环境。
